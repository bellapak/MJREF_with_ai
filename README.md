# MJREF — 조회수 · 좋아요 · 댓글 수 직접 기록 (2026-10-26)

## 기준 및 변경 범위
- 바로 이전 **조회수·좋아요 기록본(2026-10-26)**의 `app.js`, `index.html`, `styles.css`에 **댓글 수**만 증설했습니다.
- 신규 등록 모달과 카드 상세 편집에서 `댓글 수`를 수동 기록합니다.
- 카드 아래에 `조회 / 좋아요 / 댓글` 3개 지표를 표시합니다. 마지막 변경 일시는 기존 `recordedAt`을 공유합니다.
- `socialMetrics.comments` 필드를 추가하며 기존 `views`, `likes`, `recordedAt`, 분류 태그, 이미지·캐러셀, AI 영상 분석 결과를 그대로 보존합니다.
- 이전 레퍼런스는 댓글 수가 **미입력(null)** 으로 시작합니다. 실제 숫자 `0`과 빈칸을 구분합니다.
- 0 이상의 정수와 쉼표 입력(예: 1,234)을 허용하고, 다른 입력은 오류를 표시합니다.
- API·AI 크레딧 사용 없음. 기존처럼 브라우저 로컬은 자동 저장, Drive는 상단 **Drive에 저장**을 누를 때만 기록합니다.

## GitHub Pages 적용 방법
1. **코드와 로컬의 미동기화 레퍼런스 데이터를 먼저 백업**합니다.
2. ZIP 안의 `app.js`, `index.html`, `styles.css`를 저장소 루트의 같은 이름 파일로 **교체**합니다. 줄 단위로 이어 붙이지 마세요.
3. GitHub Desktop에서 변경 내용 확인 → Commit → Push origin.
4. 배포 후 새 레퍼런스를 추가하거나 기존 카드 상세의 댓글 수 입력·수정 저장을 테스트합니다.
5. 페이지 새로고침 후 수치가 유지되는지 확인하고 필요한 경우 **Drive에 저장** 버튼을 누릅니다.
6. `Drive 불러오기`는 로컬 미저장 변경사항을 덮어쓸 수 있으므로 사용 전 유의하세요.

- 실제 사용자 계정의 Google Drive API 저장은 이 파일 제작 환경에서 검증하지 않았습니다.
