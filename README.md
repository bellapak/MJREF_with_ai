# Reference Encyclopedia — 검색 중심 내비게이터

GitHub Pages 전용 정적 웹앱. GPT/OpenAI API 연결이 없는 수동 태그 버전입니다.

## UI 변경
- 화면 상단의 크게 강조한 통합 검색창: 제목/브랜드/메모/태그를 통합 검색
- 좌측 메뉴 트리: 콘텐츠 유형, 분류 상태, 용도/업종/혜택/색상/비주얼 스타일 등 13개 속성, 정렬
- 분류별 접기·펼치기와 전체 펼치기/접기
- 선택된 필터를 검색창 아래 칩으로 표시하고 개별 해제 가능
- '조건 초기화' 버튼으로 검색어, 타입, 분류 상태, 태그 조건 한번에 해제
- 키보드 `/`를 눌러 검색창 포커스
- 모바일에서 필터 탐색 버튼 지원

## 필터 동작
- 같은 분류 내부 태그는 OR, 다른 분류 간은 AND입니다.
- 데이터 구조/로컬 저장 키(`refboard_v31_state`)와 Google Drive 동기화 로직은 변경하지 않았습니다.
- 기존에 저장한 분류 값들은 그대로 활용됩니다.

## 배포
기존 파일을 백업하고 `index.html`, `styles.css`, `app.js`를 GitHub Pages 저장소의 해당 위치에 덮어쓰세요. 브라우저에서 강력 새로고침 후 확인하세요.

## 검증 범위
JavaScript 구문 검사 완료. 브라우저 자동 테스트는 실행 환경의 Chromium 접속 제한으로 수행할 수 없었으므로 GitHub Pages 실제 환경에서 검색/태그 저장/Google Drive 동기화를 검증하세요.
