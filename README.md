수정일: 2026-11-13. 이전 `MJREF_상세페이지_자동분류_실행복구_이미지만_20261113.zip`을 기준으로 개선했습니다.

## 설치 — 두 부분을 모두 적용해야 합니다

1. **먼저 백업:** 사이트 상단 **Drive에 저장**을 실행하고, 현재 GitHub 저장소 파일과 Apps Script의 `DetailPageClassifier.gs`를 백업합니다. Google Drive를 불러오는 버튼은 미저장 로컬 변경을 덮어쓸 수 있으니 주의합니다.
2. **GitHub Pages:** `index.html`, `app.js`, `styles.css` 세 파일을 같은 이름으로 교체한 후 배포합니다. 기존 배포 주소를 유지하세요.
3. **Apps Script:** 기존 프로젝트의 `DetailPageClassifier.gs` 파일 내용만 새 파일로 **전체 교체**합니다. `Code.gs`는 유지하고 수정하거나 삭제하지 마세요. 기존 Gemini 키를 재사용합니다. 같은 이름의 함수를 포함한 구버전 파일을 중복 추가하면 안 됩니다.
4. `pdpCheckSetup()`으로 기본 연결 확인 → `pdpClassifyNextBatch()`로 먼저 테스트합니다. 기존 15분 예약 트리거를 이미 설정했다면 동일한 함수명을 유지하므로 새로 만들 필요가 없습니다. 트리거가 없다면 `pdpInstall15MinuteTrigger()`를 직접 실행해야 예약됩니다.
5. 사이트에서 **상세페이지 모음 → AI 분류 현황 → AI 결과 반영**을 누릅니다. 버튼은 Gemini 호출이 아니라 **Drive에 저장된 결과 동기화**입니다.

- 상단 AI 분류 현황에 집계 카드, 완료 비율, 필터가 표시됩니다. 수동 분류 완료와 AI 완료를 혼동하지 않습니다.
- 상세페이지 카드와 우측 편집 창에 AI 상태, 오류 이유, 최근 분석 시각 및 재시도 예정 시각을 보여줍니다.

## HTTP 503 해결 로직

- Gemini 생성 요청에서 HTTP **503(모델 일시 과부하), 429, 500, 502, 504**가 발생하면 한 번의 실행 내 **최대 3회** 지수 백오프로 시도합니다.
- 계속 실패하면 **`retry`** 상태와 `nextRetryAt`을 JSON `items[].detailPage.pdpAi`에 보존합니다. **5분, 10분, 20분, 40분, 80분** 수준으로 예약 지연을 늘려 다음 실행에서 다시 시도합니다(작은 지터 포함).
- 동일 이미지의 반복 일시 오류가 한도를 초과하면 **`error`**로 전환하며 자동 재시도를 중단합니다. 상세 편집 창에서 **AI 재분류 요청**을 누르면 수동으로 다시 대기 상태를 만들 수 있습니다.
- 401/403(키/접근), 400(요청 형식), 404(모델) 등은 지수 재시도로 해결할 수 없으므로 별도 오류로 남깁니다. 서버 과부하 자체를 제거하거나 재시도 성공을 보장하지는 않습니다.
- 기존 버전에서 `error`로 기록된 이미지는 새 버전 설치 후 한 번 자동 재시도 가능합니다. 영상은 제외합니다.

## AI 결과 보존 방식

- `Code.gs`의 일반 이미지 AI 분류 및 기존 태그는 수정하지 않습니다.
- 사이트의 **상세페이지 AI 결과 반영**은 Drive JSON에서 **AI 분석 정보만 가져옵니다**. 일반 레퍼런스, 카피 모음, 수동으로 입력한 상세페이지 카피/메모/소구 태그를 통째로 덮어쓰지 않습니다.
- 분석값은 빈 입력칸을 채우고 소구·구성 단계는 추가하는 방식이며, 이전에 저장한 수동 카피는 우선 유지합니다. AI 분석 시각보다 **더 늦게 사용자가 수정한 페이지**는 수동 분류값을 그대로 두고 AI 기록만 보존합니다.
- 상단 **Drive에 저장** 시에는 업로드 직전에 Drive의 최신 PDP AI 기록을 다시 가져와 오래된 로컬 JSON이 AI 결과를 덮어쓰는 사고를 줄입니다.
- 편집 창에 미저장 입력이 있으면 AI 결과 반영 전에 **수정 저장**하도록 안내합니다.
- 여러 사용자가 동일한 JSON을 동시에 저장하는 상황까지 완전히 방지하는 서버 측 트랜잭션 기능은 없습니다. 일반 `Code.gs`와 PDP 분류기의 트리거가 겹치지 않게 관리하고, 여러 기기에서 동시에 같은 아카이브를 저장하지 마세요.
