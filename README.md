# MJREF — 조회수·좋아요 수 직접 기록 기능 (2026-10-26)

## 기준 코드
이번 대화에서 업로드한 `app(4).js`, `index(3).html`, `styles(3).css`를 기반으로 기능을 추가했습니다. 다른 과거 버전을 덮어쓴 복구본이 아닙니다.

## 새 기능
- 새 레퍼런스 추가창(이미지·영상·캐러셀)에 **조회수**, **좋아요 수** 입력란 추가.
- 기존 레퍼런스 카드를 열어 상세 화면에서 조회수·좋아요 수 입력 및 **수정 저장** 가능.
- 수치를 기록한 카드에서 `조회 12,345` / `좋아요 678`처럼 바로 확인 가능.
- 마지막으로 수치를 변경한 날짜·시각 자동 기록.
- 빈 입력은 `null`(미입력)이고, `0`은 실제 영(0)으로 구분함.
- 0 이상 정수와 쉼표가 포함된 표기(예: `12,345`) 입력 지원. 잘못된 값을 입력하면 저장하지 않고 오류 표시.
- `socialMetrics: { views, likes, recordedAt }`로 레퍼런스 객체에 저장. 기존 레퍼런스의 분류 태그·메모·AI 영상 분석 결과를 유지.
- 로컬 저장은 기존 방식대로 자동, **Google Drive는 상단 'Drive에 저장' 버튼을 눌러야만 전송**.
- 숫자는 직접 입력만 지원하며, SNS API에서 조회수·좋아요 수를 자동 수집하지 않습니다. AI 분석 크레딧을 사용하지 않습니다.

## 설치
1. **GitHub 저장소의 최신 코드를 별도 폴더나 커밋으로 백업**하고, 현재 열린 브라우저의 로컬 변경사항 중 미동기화 항목이 있으면 별도 백업합니다.
2. 저장소 루트의 `app.js`, `index.html`, `styles.css`를 이 ZIP에 포함된 같은 이름의 파일로 각각 **교체**합니다. 이전 코드와 줄 단위로 이어 붙이지 마세요.
3. GitHub Desktop에서 변경 파일 확인 → Commit → Push origin.
4. GitHub Pages 배포 완료 후 사이트를 강력 새로고침하고, 기존 레퍼런스가 유지되는지 확인합니다.
5. 테스트용 카드 한 개를 열어 조회수 1,234, 좋아요 56 저장 → 카드 수치 확인 → 새로고침 후 유지 확인.
6. Google Drive 백업이 필요한 경우 상단 **Drive에 저장**을 눌러 저장 완료를 확인합니다. 'Drive 불러오기'는 미저장 로컬 변경사항을 덮어쓸 수 있으니 사용 전 유의하세요.

## 변경하지 않은 기능
- 콘텐츠 영역별 상위/전용 분석 필터, 이미지 다중 드롭→캐러셀 자동 생성, 기존 AI 분류 및 영상 분석, 기존 Google Drive 재개 가능 업로드 로직.
- Apps Script `Code.gs`, `VideoAnalysis.gs`는 수정하지 않습니다. 이 기능은 API 키나 Apps Script 설정을 추가로 요구하지 않습니다.

## 검증 범위
- `node --check` 통과.
- Node 모의 검사: 레퍼런스 등록·상세 수정·미입력과 0 구분·숫자 쉼표 입력·잘못된 값 차단·로컬 JSON 복원·레거시 태그 보존·Drive 자동 저장 미호출 통과.
- 브라우저/실제 Google Drive 연동 테스트는 실행 환경의 브라우저 접근 제한으로 완료하지 못했습니다. 사용자 브라우저에서 소규모 테스트 후 배포하세요.
