# MJREF 영상 수동 분류 전용 (2026-10-26)

## 변경 범위
- 기존 최신 `MJREF_영상_자동태그_자동반영_20261026.zip` 기반 **최소 변경**입니다.
- `app.js`: 영상 전용 AI 자동 태그/프레임 추출/분석 요청/결과 동기화/20초 폴링/영상 프레임 Drive 업로드 및 대기 검사 제거.
- 영상 카드의 상세 패널에는 기존 **분석 분야 → 공통 분석 → 분야별 심화 → 비주얼** 수동 체크 태그만 남깁니다. 선택 후 `수정 저장`을 눌러 저장합니다.
- 이미지·캐러셀·영상 업로드 및 재생, 기존 데이터, 기존 분류 필터, 캐러셀, 조회수·좋아요·댓글 수, 일반 이미지 AI 분류 `Code.gs`, 브라우저 로컬 자동 저장/Drive 수동 저장은 유지합니다.
- 기존 데이터 속 `videoAnalysis` 이력은 **삭제하거나 초기화하지 않습니다**. 화면에서 사용하지 않고 신규 분석 요청을 만들지 않습니다.

## 설치 (둘 다 진행 권장)
1. **GitHub 저장소 및 로컬 변경사항을 먼저 백업하세요.** 특히 아직 Drive에 저장하지 않은 새 이미지·영상이 있으면 브라우저 데이터/IndexedDB를 삭제하지 마세요.
2. GitHub Pages 저장소의 `app.js` 파일을 이 ZIP의 `app.js`로 **교체**합니다. `index.html`과 `styles.css`는 변경하지 마세요. GitHub Desktop에서 Commit → Push origin 합니다.
3. Google Apps Script 편집기에서 기존 `VideoAnalysis.gs` 파일의 내용을 이 ZIP의 **비활성화 버전**으로 교체합니다. 이 두 함수는 호출돼도 아무 분석을 실행하지 않습니다. (대신 해당 파일을 삭제하려면 먼저 이 함수에 연결된 트리거가 없는지 확인하세요.)
4. Apps Script > 트리거(시계 아이콘)에서 `mjrefAnalyzePendingVideos` 또는 `mjrefBackfillVideoTags`에 대한 예약 트리거가 있으면 **삭제**합니다. `classifyNextBatch` 등 이미지 AI 자동 분류 트리거는 건드리지 마세요.
5. 배포 후 영상 카드 열기 → **콘텐츠 분석 분야 / 수동 필터 체크** → `수정 저장` → 상단 `Drive에 저장`. 새로고침 후 태그가 남는지 확인하세요.

## 참고
- 현재 파일의 태그는 수동 입력만 가능하며 영상 AI 크레딧을 사용하지 않습니다.
- 기존에 AI로 등록된 태그가 있다면 **삭제하지 않고 그대로 남습니다**. 필요 없는 태그는 영상 상세에서 체크 해제 후 수동 저장하면 됩니다.
- Google Drive의 기존 영상 분석 프레임 폴더는 자동 삭제하지 않습니다. 보존 여부가 확실하지 않으면 그대로 두세요.
- `Drive 불러오기`는 저장되지 않은 로컬 변경사항을 덮어쓸 수 있으니, 필요하지 않으면 누르지 마세요.
