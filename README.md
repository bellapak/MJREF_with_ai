# MJREF 상세페이지 AI 화면 간소화 · 2026-11-13

## 수정 내용
상세페이지 모음 상단의 AI 분류 현황(분석 대기/분석 중/AI 완료/재시도 예정/확인 필요/분석 실패/분석 제외/수동 분류)과 진행률, 상태 필터, 상태 설명을 화면에서 제거했습니다. 남는 버튼은 `Apps Script 열기`, `결과 반영` 두 개입니다. 상세페이지 카드의 AI 상태 배지와 상세 편집 화면의 AI 상태 기록도 표시하지 않습니다.

- **AI 분석/재시도/결과 병합 로직은 그대로 유지**됩니다. 화면만 간소화한 것입니다.
- 제품군·소구 포인트·구성 단계·콘텐츠 유형 필터, 일반 분류 상태 필터, 상세페이지 편집, 레퍼런스 원클릭·일괄 이동, 카피 연결 및 Drive 수동 저장은 유지합니다.
- `결과 반영`은 기존대로 `refboard-pdp-ai.json`을 읽고 분류 결과를 저장합니다. 성공/오류는 일시적인 토스트로 안내합니다. 이 버튼 자체가 AI 분석을 실행하지는 않습니다.
- 일반 **레퍼런스** 탭의 별도 AI 분류 UI와 스크립트는 수정하지 않았습니다.

## 설치
1. 기존 사이트에서 `Drive에 저장`으로 미저장 데이터를 백업합니다.
2. GitHub Pages의 루트에서 `index.html`, `app.js`, `styles.css`를 동일 이름 파일로 교체하고 배포합니다.
3. **Apps Script의 `Code.gs` 및 `DetailPageClassifier.gs`는 모두 그대로 유지**합니다. Gemini/OpenAI API 키도 변경하지 않습니다.
4. 상세페이지 모음에서 버튼 두 개만 나타나는지, `결과 반영` 클릭 시 성공/실패 안내가 나오는지 확인합니다.

## 검증 및 제한
- `app.js` 문법 검사와 화면/정적 기능 검사를 실시했습니다.
- 실제 사용자 Drive 인증과 배포 환경의 API 호출은 수행하지 않았습니다.
- 이전에 AI가 실패한 이미지는 상태 표시만 숨겨집니다. 서버 측 AI 재시도는 Apps Script 설정에 따라 계속 진행됩니다.
