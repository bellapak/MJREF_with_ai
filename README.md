# MJREF 상세페이지 — AI 결과 반영 연결·화면 안내 수정 (2026-11-16)

## 이번에 확인한 문제

- 마지막으로 제공한 사이트 버전에는 `pdp-ai-sync-note` 영역이 없는데, 일부 오류 처리 코드가 여전히 그 요소에만 상세 설명을 쓰고 있었습니다. 사용자에게는 2.2초 후 사라지는 토스트만 보였습니다.
- 분석 결과 파일에는 `processing` 등 **진행 상태**만 있을 수 있습니다. 이 상태는 Gemini/OpenAI 분석이 완료되었다는 뜻이 아니므로, 해당 자료를 가져와도 소구 포인트가 채워지지 않습니다.
- 기존 병합 로직은 AI 상태 JSON이 동일하면 이미 저장된 `done` 결과의 소구 내용이 누락되어 있어도 다시 채우지 않았습니다.
- `pdpCheckSetup()`은 연결 진단이며 실제 분석이 아닙니다. 이미지 분석은 `pdpClassifyNextBatch()`를 실행해야 합니다.

## 수정

1. **버튼 두 개 유지**: `Apps Script 열기`, `결과 반영`. 이전에 숨긴 AI 상태 카드, 상태 배지는 복원하지 않습니다.
2. 결과 반영 버튼 클릭 시에만 하단에 **지속 표시되는 메시지** 출력. 성공, 결과 없음, 완료되지 않음, ID 불일치, Drive 권한 오류 등을 구분합니다.
3. AI 상태 기록이 이미 로컬과 동일하더라도 완료(`done`) 상태의 소구 내용이 누락되었다면 다시 병합합니다.
4. 사용자 직접 입력/카피를 삭제하지 않고, AI 데이터는 비어 있는 항목을 채우거나 확인된 태그를 중복 없이 추가합니다. 사용자의 수동 편집 시점이 AI 결과보다 더 최근인 경우 수동 수정 사항 보호를 우선합니다.
5. 결과가 실제 소구 필드에 적용되면 **브라우저에 즉시 저장**하고 Drive 미저장 상태로 표시합니다. 다른 기기와 동기화하려면 상단 `Drive에 저장`을 누릅니다.
6. 캐시 버전 쿼리로 구버전 app.js/styles.css를 계속 불러오는 상황을 완화했습니다.

## 적용

1. **기존 GitHub 파일과 운영 데이터를 백업**하세요. 미저장 로컬 변경이 있다면 사이트 상단에서 `Drive에 저장`을 먼저 실행하세요.
2. ZIP 안의 `app.js`, `index.html`, `styles.css` 세 파일을 **같은 배포 저장소의 루트**에서 동일한 이름으로 교체하고 배포하세요.
3. **Apps Script의 `Code.gs`, `DetailPageClassifier.gs`는 이번 변경에서 수정할 필요가 없습니다.** 두 분류기의 AI 모델/API 키 설정도 변경하지 않습니다.
4. Apps Script에서 `pdpClassifyNextBatch`를 실행한 뒤 실제 완료 로그(`done` > 0 또는 결과 `done`)를 확인하고, 사이트 상세페이지 모음의 `결과 반영`을 클릭하세요.
5. 화면의 메시지를 확인하세요. AI로 소구 내용이 새로 채워졌다면 상단 `Drive에 저장`으로 반영 내용을 Drive에도 저장하세요.

## 로그를 읽는 법

이전에 제공된 `pdpCheckSetup()` 로그는 `detailPages:30`, `imageEligible:30`, `pending:29`, `statuses.processing:1`, `resultsSaved:1`로, 상세페이지가 정상 인식되어도 **완료된 소구 분석이 0건**인 상태였습니다. 이 상황에서 결과 반영 버튼만 누른다고 제품군이나 소구가 만들어지지 않습니다.

- `pdpCheckSetup` 실행 = 설정/대기열 진단
- `pdpClassifyNextBatch` 실행 = 원본 이미지 AI 분석
- 상세페이지 `결과 반영` 클릭 = 이미 저장된 AI 분석 결과를 사이트로 가져오기
- 사이트 `Drive에 저장` 클릭 = 사이트에서 병합한 분류/수정 내용을 일반 레퍼런스 JSON에도 보존

이번 수정으로 화면이 진단 이유를 알려주지만, **AI API가 실제 분석에 실패한다면 프런트엔드만으로 성공 결과를 만들 수는 없습니다.** 기존 `Code.gs` 원본 및 운영 Drive/Gemini/OpenAI 서비스에 직접 로그인한 통합 검증은 수행하지 않았습니다.
