# MJREF에서 노션으로 보내기

카드 상세에서 **노션으로 보내기**를 누른 뒤 새 창에서 분류와 저장을 선택합니다. 일반 카드와 상세페이지 카드 모두 지원합니다. 같은 카드를 다시 보내면 제목·원본 링크·메모를 갱신합니다. 다른 노션 속성과 본문은 유지합니다. 수집함으로 재전송할 때 이미 붙인 분류는 유지합니다. 이미지는 원본 링크나 기존 Drive 파일 링크로 열 수 있습니다.

## 처음 한 번 설정

1. 노션에서 내부 연결을 만들고 콘텐츠 읽기·추가·수정을 허용합니다. 연결의 콘텐츠 접근 대상에 실제 **자료함** 데이터베이스를 추가합니다. 연결 비밀값은 다음 단계에서 사용합니다.
2. 본인 계정에 별도 Google Apps Script 프로젝트를 만듭니다. **Code.gs**와 HTML 파일 **Confirm**에 이 폴더의 해당 파일 내용을 넣습니다.
3. 프로젝트 설정의 스크립트 속성에 **NOTION_TOKEN**과 **NOTION_DATA_SOURCE_ID**를 추가합니다. 각각 노션 연결 비밀값과 자료함 데이터 소스 ID를 넣습니다. 비밀값을 GitHub나 MJREF 입력창에 붙여넣지 마세요.
4. **배포 → 새 배포 → 웹 앱**에서 실행 사용자는 **나**, 액세스 권한은 **나만**으로 배포하고 배포 주소(/exec)를 복사합니다. Google의 권한 승인 화면이 뜨면 해당 계정에서 승인합니다.
5. 수정된 MJREF 사이트에서 **노션으로 보내기**를 눌러 배포 주소를 한 번 입력합니다. 이후 같은 브라우저에서 주소를 기억합니다. 주소 변경은 버튼 옆 설정을 사용합니다.

데이터베이스 속성은 제목(제목), 링크(URL), 기억할 한 줄(텍스트), MJREF ID(텍스트), 노트(다중 선택)를 사용합니다. 비어 있는 노트는 수집함에 표시됩니다. 카드가 이미 등록되어 있다면 기존 노트에 선택한 분류를 추가합니다. 전송할 때 표시된 입력값을 사용하며 MJREF의 브라우저 저장과 Drive 저장은 각각 기존 버튼으로 실행합니다.
